# Excalidraw 详细使用指南

Excalidraw 是手绘风格的白板工具，适合画流程图、系统架构、会议草稿、简单线框原型。可在线使用，也可自行部署。

- 在线：https://excalidraw.com
- 源码：https://github.com/excalidraw/excalidraw

---

## 一、三种使用方式

### 1. 官方在线（最快）

打开 https://excalidraw.com 即可画。适合个人草稿、临时协作。

注意：浏览器端存储与分享方式以站点当前行为为准；重要图请**导出备份**。

### 2. 桌面感 / PWA

现代浏览器可「安装为应用」或固定标签页，减少找网址成本。

### 3. 自托管（团队、内网、合规）

需要把前端（及可选后端协作服务）部署到自己的服务器或静态托管。按官方仓库 README 与 Docker 说明操作。自托管时可控制数据是否出内网。

---

## 二、界面与基本操作

| 操作 | 说明 |
|------|------|
| 形状 | 矩形、菱形、椭圆、箭头、线条、文字、笔迹 |
| 选择 | 点击或框选；可对齐、分组 |
| 样式 | 描边、填充、字体、粗糙度（手绘感） |
| 画布 | 拖动画布、缩放；网格与吸附有助于排版 |
| 图层感 | 通过前后顺序与分组管理复杂图 |

快捷键因版本可能略有差异，可在帮助菜单中查看。

---

## 三、导出与导入

建议养成导出习惯：

| 格式 | 用途 |
|------|------|
| `.excalidraw` | 源文件，可再编辑，适合 Git |
| PNG / SVG | 贴文档、PPT、README |
| 剪贴板 | 快速粘贴到其它应用 |

导入源文件可继续改图。把 `.excalidraw` 放进仓库时，团队可审阅图稿变更。

---

## 四、库（Library）

常用组件（例如「用户」「数据库」「箭头组」）可加入库，下次一键拖入，统一风格。

适合：架构图图例、UML 简化符号、产品流程图例。

---

## 五、协作

在线版支持只读链接或协作房间（以产品当前功能为准）。自托管协作需额外部署实时服务，参考官方文档。

协作时约定：

- 谁维护「终稿」文件
- 导出 PNG 是否与源文件同步更新
- 敏感架构是否允许出内网

---

## 六、本地开发启动（贡献或二次开发）

```bash
git clone https://github.com/excalidraw/excalidraw.git
cd excalidraw
yarn          # 或按官方当前包管理器说明
yarn start
```

用于调试与学习源码；普通画画用在线版即可。

---

## 七、使用场景示例

1. **评审前**：先画系统边界与数据流，再开会
2. **README**：导出 SVG 嵌入 GitHub 文档
3. **教学**：逐步展示算法或业务流程
4. **产品**：低保真页面框图，避免一上来就高保真浪费时间

---

## 八、常见问题

| 问题 | 建议 |
|------|------|
| 刷新后图没了 | 检查是否仅本地缓存；重要图导出源文件 |
| 导出模糊 | 提高导出倍率或用 SVG |
| 字体不理想 | 在属性里换字体；嵌入文档时注意跨设备字体 |
| 太大卡顿 | 拆图、减少笔迹点、合并重复元素 |
