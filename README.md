# Excalidraw 使用指南

手绘风格白板，适合流程图、架构图、原型草图。

- 在线：https://excalidraw.com
- 项目：https://github.com/excalidraw/excalidraw

## 直接使用

打开 https://excalidraw.com 即可绘制，可导出 PNG、SVG 或源文件。

## 本地运行

```bash
git clone https://github.com/excalidraw/excalidraw.git
cd excalidraw
yarn
yarn start
```

自托管生产环境可参考官方 Docker / 构建说明。

## 小技巧

- 常用形状与组件可收入库中复用
- 源文件适合纳入版本管理
- 协作功能取决于部署方式
